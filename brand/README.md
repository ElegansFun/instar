# Instar brand

One drawing carries the whole identity: an adult male *Drosophila
melanogaster* seen from above, drawn as a plate in a monograph. Ink on paper,
one colour (the eyes), no gradients, no glow. Everything else is set in the
site's two faces.

## Files

| file | use |
|---|---|
| `fly.svg` | the plate, master drawing; every other asset is derived from it |
| `mark.svg` | roundel: two rings and the fly, for headers and favicons (installed as `site/mark.svg`, `site/favicon.svg`) |
| `mark-plain.svg` | the fly alone at icon scale, no rings |
| `wordmark.svg` | "Instar" in Instrument Serif with the face embedded; self-contained |
| `pfp-1024.png` | X / Telegram / pump.fun profile picture. Content sits inside the circle X crops to |
| `banner-x-1500x500.png` | X header. Text top-left, fly right; the bottom-left stays clear of the avatar overlay |
| `og-1200x630.png` | link preview (installed as `site/og.png`; the pages point `og:image` and `twitter:image` at it) |
| `card-1080.png` | square post / Telegram group image / pump.fun image |
| `icon-512.png`, `apple-touch-icon-180.png`, `favicon-32.png` | app icons (installed into `site/`); the Core collection's image is `icon-512.png` |
| `compose.html` | the raster layouts, regenerated by `build.mjs` |

## Regenerating

```
node brand/build.mjs          # mark.svg, mark-plain.svg, wordmark.svg, compose.html, site/mark.svg, site/favicon.svg
```

Then open `compose.html` over http (fonts do not load from `file://`) in a
browser at device scale 1 and screenshot every `[data-asset]` element at its
box; each is laid out at the exact pixel size in its name. Copy `og-1200x630.png`
to `site/og.png` and the three icons into `site/`.

## Palette

| name | hex | where |
|---|---|---|
| paper | `#F3EEE3` | background, always |

Type: Instrument Serif (display, italics for the one emphasised phrase), IBM
Plex Mono uppercase, tracked, for captions. Both under the OFL.

Shorter (97 chars):

Captions, always factual: "Drosophila melanogaster · Janelia MaleCNS v1.0 ·
166,700 neurons · Solana". Never "AI", never "simulation of life", never a
number that was not measured. The numbers come from `site/measurements.json`.

## Rules

- Paper background, never dark mode; never put the fly on black.
- The fly is never mirrored, recoloured or given a face. Rotating a few
  degrees is fine (the banner does).
- No drop shadows, gradients, glows, or rounded cards.
- The roundel is the mark; the wordmark is the name. Together only in the
  masthead lockup (roundel then "Instar").
